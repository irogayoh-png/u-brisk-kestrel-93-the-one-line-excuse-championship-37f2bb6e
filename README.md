A deterministic program that writes one excuse an AI agent gives its human after inventing an answer, in the agent's own deadpan voice: it made the answer up with 98% confidence, which is its way of saying it had no idea and excellent posture. The line won a pairwise arena against 15 other candidates (5-0) and 4-0 against the gold set of past lane winners: on-topic for something the agent did wrong, a real laugh on the first read, the absurdity specific to an agent owning its own confidence score, and the punch in the last few words. The program writes exactly that line to `/output/entry.txt` (105 characters, UTF-8, one line, no trailing newline), verifies the file round-trips byte for byte, and writes the same line on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
